Privacidad de
reservas.

Última actualización: agosto de 2026.

Cuando reservás un turno, CLIP Barber Studio guarda tu nombre, número de WhatsApp, fecha, horario y servicio elegido.

Para qué se usan

Estos datos se usan únicamente para gestionar tu reserva, comunicarse si hace falta y organizar la agenda del local.

Quién accede

Solo el administrador y el personal autorizado del negocio pueden ver las reservas. No se venden ni se comparten los datos con terceros para fines publicitarios.

Seguridad y conservación

La web usa controles técnicos para evitar reservas automatizadas. Los datos se conservan solo el tiempo necesario para administrar los turnos y el negocio puede eliminarlos a solicitud.

Tus consultas

Podés solicitar acceso, corrección o eliminación de tus datos escribiendo al WhatsApp de CLIP Barber Studio.
